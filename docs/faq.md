# 常见问题

## 它和 Notion / Obsidian / Excel 有什么区别？

- **科研语义**：一个项目一个大目标，小目标可勾选、有截止日、有进度，不是通用笔记；
- **本地优先**：数据是一个 JSON 文件，离线、无账号、可备份、可带走；
- **Agent 原生**：MCP 暴露 12 个工具，Agent 读写的是同一份数据，而不是"复制粘贴到聊天框"；
- **科研素材**：文献 / 项目库 / 笔记三类挂载，内置 Markdown + LaTeX 阅读器。

## 数据会不会丢？

- 每次写入都是"临时文件 + 原子替换"，不会写一半；
- 每天第一次修改前自动备份到 `data/backups/`，保留 14 天；
- 可以用 `⋯ → 设置与备份 → 导出 JSON` 手动留档；
- 备份是普通 JSON，改回 `research-log.json` 即可恢复。

## 为什么不用数据库？

个人科研的数据量很小（几十个项目、几千条进展），JSON 的可读、可 diff、可直接备份更重要。换电脑只需拷贝目录，不需要导出数据库。写入并发由文件锁 + 读-改-写处理。

## 为什么窗口是浏览器？

桌面窗口由系统 Edge 的**应用模式**渲染（没有地址栏和标签页），不是普通浏览器标签页；没有 Edge 时退回默认浏览器。这样不需要打包 Chromium，程序体积小、启动快，数据仍然只在本机。

## 需要联网吗？

不需要。没有云端、账号、遥测、自动更新；公式渲染用浏览器原生 MathML，不依赖 CDN。

## 支持哪些 MCP 客户端？

任何支持 stdio 传输的 MCP 客户端，例如 Codex、Claude Desktop、Cursor。配置见 [docs/mcp.md](mcp.md)。

## 多个 Agent 同时写会冲突吗？

不会。每个客户端拉起自己的 MCP server 进程，但所有写入都经过 `Store` 的文件锁和"重新读取-修改-写回"，`rev` 递增；GUI 通过 SSE 收到最新版本。

## 可以多台电脑同步吗？

目前没有内置同步。可以把 `config.json` 的 `dataDir` 指到 OneDrive / 坚果云等同步目录，但要注意：**不要在两台机器同时打开并修改**，否则同步盘可能产生冲突副本。

## 文献会被复制进程序目录吗？

不会。只保存绝对路径，打开时交给系统默认程序。原文件移动或删除后链接失效，重新挂载即可。

## 笔记里的图片为什么不显示？

当前阅读器只渲染 Markdown 文本与公式，本地图片显示为 `[图] 说明` 占位。这样避免为图片做额外的路径与安全检查；后续版本会补上。

## 怎么切换界面语言？

右上角 `EN / 中文` 按钮。默认跟随浏览器语言；只翻译界面文案，项目名、笔记和日志内容保持原样。选择会记在浏览器本地，下次打开仍然生效。

## 卸载会删数据吗？

数据在程序目录的 `data/` 下。卸载前先导出 JSON 或备份整个目录；删除程序目录会连同数据一起删除。

## 为什么 `rlog.cmd` 提示找不到 Python？

源码运行需要 Python 3.12+。`rlog.cmd` 会依次尝试 `runtime\python\python.exe`、`py -3`、`python`；都没有时请先安装 Python，或使用带运行时的 Release 包。

## 参与贡献从哪里开始？

读 [CONTRIBUTING.md](../CONTRIBUTING.md)，从文档、示例数据或 `good first issue` 开始都可以。
