# 使用说明

一个本地优先的科研项目与进展管理工具：按「未来 / 进行中 / 已完成」管理项目，每个项目一句大目标 + 若干可勾选的小目标，右侧记录每天的进展。

## 启动

**Release 包**：

- 双击 `科研日志.exe`，或运行 `run.cmd`；
- 第一次启动会自动创建 `data/`，等两三秒窗口出现；
- 想固定到任务栏：窗口打开后，右键任务栏图标 → **固定到任务栏**。

**源码**：

```bat
run.cmd
:: 只启动引擎，不打开窗口（适合脚本/远程）
run.cmd --no-window
```

`run.cmd` 会依次尝试项目内的 `runtime\python\python.exe`、`py -3`、`python`，再调用 `launch.py`。

也可以只启动引擎，用浏览器访问：

```bat
python app\server.py
:: 打开 http://127.0.0.1:47823/
```

> 窗口由系统 Edge 的应用模式渲染（没有地址栏和标签页）；没有 Edge 时退回默认浏览器。

## 界面

- **左侧**：项目列表，可按状态筛选；进度条是小目标的完成比例。
- **中间**：默认是看板，三列对应「未来 / 进行中 / 已完成」，卡片可以直接拖到别的列；点进项目就是大目标、成功判据、目标日期和小目标清单。
- **右侧**：这个项目的进展记录，`Ctrl + Enter` 发送。
- **语言**：右上角 `EN / 中文` 切换界面语言，默认跟随浏览器语言；只翻译界面，项目名和笔记内容保持原样。

常用操作：

| 操作 | 方式 |
|---|---|
| 新建项目 | 右上角「新建项目」或 `Ctrl + N` |
| 搜索 | `Ctrl + F`，搜项目名、大目标、小目标、备注 |
| 添加小目标 | 清单底部输入，回车连加 |
| 打勾 / 改文字 | 点方框；文字直接点进去改 |
| 备注、截止日 | 悬停小目标行右侧的便签 / 日历图标 |
| 小目标排序 | 悬停小目标左侧的六点手柄，按住拖到目标位置；或聚焦手柄后 `Alt + ↑ / ↓` |
| 改项目状态 | 详情页状态下拉，或看板拖拽 |
| 返回 | `Esc` 或左上角「全部项目」 |
| 撤销删除 | 删除后点提示条上的「撤销」，或 `Ctrl + Z` |
| 复制某条进展 | 拖选文字后 `Ctrl + C`；或悬停该条，点右上角的复制图标 |
| 复制整段进展 | 点「最近进展」标题右侧的复制图标，按时间顺序复制当前列表（带日期和项目名） |

第一次打开是空的，可以先点「载入示例」看看结构，或导入 `examples/demo-data/research-log.json`。

## 资料、项目库与笔记

项目详情里的「资料与项目库」分三类，每类都可以挂多个：

- **文献**：论文 PDF 或整个文件夹，点开用系统默认阅读器；右侧文件夹图标在资源管理器里定位；
- **项目库**：代码 / 数据目录，点开用资源管理器打开，方便直接跳到项目根目录；
- **笔记**：Markdown 文件，点开是内置阅读器，支持标题、列表、表格、代码块、任务清单和公式。

每类右上角的加号都支持「拖入文件夹 / 文件」「选择文件夹」「选择文件」；三个按钮只是预先指定了归类。旧数据里没有分类的资料会自动归到「文献」。

### 内置 Markdown 阅读器

笔记（`.md` / `.markdown` / `.txt`）点开后在窗口内阅读，不跳外部程序：

- 支持 `$...$` 行内公式和 `$$...$$` 块级公式，用浏览器原生 MathML 排版（分数、上下标、根号、求和积分、矩阵都能显示）；
- 支持标题、列表、任务清单、表格、代码块、引用、链接；
- 顶部显示文件路径和更新时间，可以「在文件夹中显示」；
- 按 `Esc` 或点遮罩关闭；
- 暂不支持本地图片（会显示成 `[图] 说明` 占位），外部链接会用浏览器打开。

## 本周与回顾

左栏顶部的「本周」把散在各项目里的时间信息汇总到一起：

- **逾期 / 今天 / 未来 7 天**：来自小目标的截止日期，逾期会标红；
- **本周完成**：最近 7 天勾掉的小目标；
- **本周进展**：最近 7 天记录的进展；
- **久未更新**：14 天以上没动过的项目。

点任意一条会跳到对应项目，并高亮那条小目标。右上角「复制回顾」会把上面这些整理成一段 Markdown 周报，直接粘贴到组会材料或周报里。

## 数据与备份

- `data/research-log.json`：全部数据，普通 JSON，可以用任何编辑器打开或备份。
- `data/backups/`：每天第一次修改前自动备份一份，保留最近 14 天。
- 右上角 `⋯` →「设置与备份」里可以导出 **Markdown**（项目报告 / 周报）或 **JSON**，也可以导入 JSON 覆盖。
- 换电脑：把整个程序目录拷走即可，数据跟着程序走。

## 配置

`config.json`：

```json
{
  "dataDir": "data",
  "port": 47823
}
```

- `dataDir`：数据目录。默认 `data` 是相对程序目录的；也可以填绝对路径，比如 `D:\\科研\\日志`。
- `port`：本地端口。被占用时会自动往后找下一个。

## 用智能体管理（可选）

程序自带命令行入口 `rlog.cmd`，读写的还是同一份 `data/research-log.json`：

```text
rlog.cmd list                                  列出项目
rlog.cmd show "示例：蛋白质折叠"                   看一个项目的目标与进展
rlog.cmd add "示例：蛋白质折叠" "复现一组公开数据"     加一个小目标
rlog.cmd done "示例：蛋白质折叠" "复现一组公开数据"    打勾
rlog.cmd note "今天把模型参数调好了" --project "示例：蛋白质折叠"
rlog.cmd add-project "新项目" --status planned --goal "……"
rlog.cmd export md                             导出 Markdown
```

- 不需要打开窗口；窗口开着时，命令行写入会在约 1 秒内自动刷新。
- 加 `--json` 输出机器可读结果，方便程序或智能体解析。
- 删除项目必须加 `--yes`；项目/小目标重名时命令会列候选。
- 给 Codex、Claude 这类工具用时，让它在仓库目录下打开，同目录的 `AGENTS.md` 已经写好了规则和全部命令。
- 支持 MCP 的客户端可以直接调用 `log_*` 工具，配置和工具清单见 [docs/mcp.md](mcp.md)。
- 完整命令：`rlog.cmd --help`。

## 常见问题

- **双击后没反应**：第一次启动要拉起本地引擎，等两三秒；仍没反应就再双击一次。任务管理器里能看到 `pythonw.exe` 说明引擎已在运行。
- **窗口提示 Edge 实例权限不一致**：说明系统里有一个以管理员身份运行的 Edge 实例。点「是」让它用普通权限重启即可；程序本身不需要管理员权限。
- **想换数据位置**：改 `config.json` 里的 `dataDir`（相对程序目录或绝对路径），重启程序。
- **想换端口**：改 `config.json` 里的 `port`，重启程序。
- 更多问题见 [docs/faq.md](faq.md)。

## 说明

- 窗口用系统自带的 Edge 内核渲染，是独立窗口（没有地址栏和标签页），所以不需要额外安装浏览器内核。
- 关掉窗口后，后台的本地引擎大约 8 秒后自动退出。
- 目前只在本机保存，不做云同步；需要多设备就把 `dataDir` 指到 OneDrive / 坚果云的同步目录，并注意不要同时修改。
- 卸载：关掉窗口，删除整个程序目录即可（数据也在里面，删之前先导出备份）。
