## 更远

- [ ] 可选的端到端加密同步（不依赖第三方网盘）；
- [ ] 插件式面板（周报模板、统计图表）；
- [ ] 原生窗口外壳（WebView2 / Electron），摆脱浏览器依赖；
- [ ] 论文写作辅助：把项目进展整理成提纲/材料清单。

## 非目标

- 不做云端账号体系；
- 不做移动端；
- 不做多人实时协作（至少近期不做）；
- 不把用户数据上传到任何服务器。
