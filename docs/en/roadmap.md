# Roadmap

[简体中文](../roadmap.md) | English

## v0.1 (current)

- [x] Project board: planned / active / done, drag cards;
- [x] Main goal, success criteria, target date;
- [x] Milestones: checkboxes, due dates, notes, drag-and-drop ordering;
- [x] Progress log, weekly view, one-click weekly review;
- [x] Papers / repositories / notes, native drop window;
- [x] Built-in Markdown + LaTeX (MathML) reader;
- [x] CLI and MCP sharing the same Store;
- [x] Atomic writes, daily backups, file watcher + SSE;
- [x] Export Markdown / JSON, import JSON;
- [x] Chinese / English UI.

## v0.2

- [ ] One-click MCP client configuration (Codex / Claude / Cursor);
- [ ] MCP Resources / Prompts: weekly review, project summary;
- [ ] Automated tests covering Store / CLI / MCP / HTTP;
- [ ] GitHub Actions: pytest + ruff + JS syntax checks;
- [ ] More sample data and screenshots;
- [ ] One-command release packaging.

## v0.3

- [ ] Cross-project paper library;
- [ ] Reminders and calendar integration;
- [ ] Local images in the note reader;
- [ ] Better search (full-text progress, date filters);
- [ ] English UI polish.

## Later

- [ ] Optional end-to-end encrypted sync (no third-party cloud required);
- [ ] Plugin panels (report templates, charts);
- [ ] Native window shell (WebView2 / Electron), removing the browser dependency;
- [ ] Writing assistance: turn project progress into an outline or materials list.

## Non-goals

- No cloud account system;
- No mobile app;
- No real-time multi-user collaboration (at least for now);
- Never upload user data to any server.

The roadmap changes with feedback; vote or propose scenarios in Issues.
